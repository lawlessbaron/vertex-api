# vertex-api: notes for Claude

- **Separate from VERTEX on purpose.** Don't add VERTEX features here, and don't read VERTEX's database. Everything about accounts goes over `server/link.js` (VERTEX side: `gridfinity-generator/server/api-link.js`).
- **Ship with the test guard:** `npm test 2>&1 | grep -q "^# fail 0" && git add -A && git commit … && git push`. Never push without it.
- **Keep the AI under wraps:** no engine or vendor names (the models behind the tracer, GPU hosts) in public pages, the docs, error messages or CHANGELOG.md.
- `engine/` is generated by `scripts/sync-engine.mjs`. Don't edit it by hand; change VERTEX and re-sync.
- Pages can't use inline `style=` attributes (the CSP blocks them); set styles from JS or CSS classes. `{{year}}` and `{{vertex}}` are filled in by the server.
- Keep `CHANGELOG.md` current on every ship.
