How this page works

Every five minutes the API checks itself: it builds a real model, reads its database and looks at the webhook queue. Real calls count too. Server errors that callers get mark a day down, but a caller's own mistakes, like a wrong setting or a missing key, don't. When something goes wrong, we post here and keep updating until it's fixed. Add an incident.updated webhook in your console to hear about it on your own server, or follow the RSS feed.
